School Administrator — Getting Started

School ERP + Learning Management System

As the School Administrator you set up the school and everything inside it. Follow the steps in order — each step depends on the one before it (you cannot add students before classes exist).

1. Create your school account

  1. Go to the EduBridge sign-up page and choose "Register a School".
  2. Enter your school name, your name, email and a password. This makes you the School Admin.
  3. Log in. You land on the School Dashboard with the module menu on the left.
  4. Open School → Profile and complete the school details (address, logo, contact).

2. Build the academic structure (do this first)

  1. Go to School → Students area → Classes. Add each class (e.g. Class 6, 7, 8).
  2. For every class, add its Sections (A, B, …).
  3. Go to Curriculum / Subjects. Add subjects for each class.
  4. You will assign a teacher to each subject in step 4 — leave it for now if no teachers yet.

3. Invite teachers & staff

  1. Go to School → Staff → Invite. Enter each teacher/staff email and send the invite.
  2. They receive an email link to set their own password (Accept Invite).
  3. Alternatively, share the School Join Code (School → Staff or Join Code) so they can self-join.

4. Assign teachers to subjects

  1. Return to Subjects and set the teacher for each subject from the dropdown.
  2. This is what makes attendance, marks and LMS appear in each teacher's portal.

5. Add students & guardians

  1. Go to School → Students → Add Student. Pick the class and section.
  2. Add the student's Guardian (parent) details — this generates a portal PIN.
  3. Share each student's Class Join Code + portal PIN so students and parents can log in.

6. Turn on the day-to-day modules

  1. Fees: create fee categories → fee structures per class. Record payments and view due/defaulter reports.
  2. Timetable: build periods per class; conflicts are flagged automatically.
  3. Exams: create exams → enter marks per subject → generate report cards.
  4. Communication: post announcements; parents/teachers get notifications.

7. Optional modules

  1. Transport: add bus routes, stops, and assign students to a route.
  2. Hostel: add a hostel block, rooms, and allot students; set the mess menu.
  3. Library: add books; issue and return them; collect fines.
  4. Events: create events and upload photos/videos for students & parents to see.
  5. Store: add purchasable items and record student purchases.
